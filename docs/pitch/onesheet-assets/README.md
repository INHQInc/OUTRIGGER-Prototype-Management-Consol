# One-sheet assets

Screen captures used in the Prism executive one-sheet
(`https://claude.ai/artifact/7zZ1ZjzS8ubrkDzGFsKAmG`, PDF on Bryan's Desktop).

**Committed: the `web/` set and the two readout emails**, about 2.8 MB
together. Those are the images the one-sheet actually embeds.

**Git-ignored: the full-resolution originals** — the PNG captures and the
`kbr-mockup-*.jpg` pair, roughly 90 MB between them. They are re-capturable
from the prototype and not worth the repo weight.

| Prefix | What it shows |
|---|---|
| `before-` | The production destination selector, before |
| `ds-` | The destination-selector prototype: grid, map states, a property card, mobile |
| `kbr-` | The KBR mockup arms, showing the scale of change one brief can carry |
| `readout-email-` | Prism's own readout email, as the results section shows it |
| `traditional-` | A traditional agency spec document, for the old-way lane |
